# Dark Universe: Outlaws —— BOOK DESC 第 7 批（行 1543~1334）
1543	我一直告诉自己这只是太空垃圾。机甲装甲从某场没人好好记录的战斗中剥落，遥测循环着它自己的最后时刻，直到电池耗尽。可那残骸里的数字，在该有伤痕的地方太干净，在该可靠的地方又恰好弯折，像有人打算回来把故事改写完，却始终没能回来。感觉就像走进一个凶手清理现场清到一半被打断的犯罪现场。\n\n我盯着它越久，它就越和我无意中绊到的其他一切对得上。一桩在主人还在收拾行李时就自我撤销的农场查封。一块半埋在灰尘里的数据板，满是几乎进了系统的草稿条目。一个跃迁节点，它的时序让我牙齿发痒，尽管星图说一切正常。都是些小事，那种你会归咎于疲惫文员和懒惰技工的小事。可合在一起看，就像有人在很久以前就开始拉扯定居星系群的线头，然后只是习惯了把线尾一直那么吊着。
1720	HM-6310 还在外面，悬在信标之间，像一个没人愿意想完的坏念头。我是在一间破败的码头酒吧里撞见它的 ID 的，埋在一个太空人的故事里——他赌咒说那只是个玩笑。死海军船壳，通讯上有干净的切口，没有登船留下的烧痕，没有信标循环。只有沉默，以及深埋在三级菜单底下的一行备注，写着"作战损失"，用的是审计员在不想知道更多时才会用的那种措辞。\n\n让我挥之不去的不是那艘船本身，而是它周围的图案。运输队为"效率"被改道，护航船稍微来晚一点，巡逻因为一些听起来很合理的原因被挪到旁边的星区——直到你意识到他们总是把某条航道留薄。然后有东西消失了，大家都耸耸肩，怪劫掠者、怪设备、怪运气不好。没人提那些互相吻合的信号盲区窗口，也没人提越靠近新亚特兰蒂斯、记录就变得越整洁这件事。每次我提起，人们都笑得太快，像他们害怕一旦停止开玩笑，真相就会落在懦弱与算计之间的某个地方。
1092	我是卡伦·罗克，在有人觉得这段不方便、把驱动器擦干净之前把它记下来。模块死一般安静，只有风扇和我自己的呼吸，可控制台讲出的故事比大多数船长一辈子讲的都要响。我像个好小偷追查一笔付款那样追查那些数据分叉，顺着那些本不该弯折的跃迁、那些绕经合同从未提及之处的数据包。每次痕迹变模糊，同一个船号就会重新出现在被擦洗过的访问备注和贸易管理局打了一半涂黑标记的审计标签里。有人以为把那么多交通量穿过一艘单一货船很隐蔽，以为只要把它埋进例行货运里就没人会注意。也许在一段时间里，他们是对的。可我们在外标附近扒下来的损坏信标日志、霓虹城下层关于幽灵航线的低语，还有那则人人都假装不记得的独立盟紧急广播，全都指回同一件事：一艘跑了太多"幸运"跃迁的货船，和一名每次被提起、声音都会更低的飞行员。
1084	我在页边空白里追这个名字追了好几个月，到现在还是不确定它到底属于一个人、一个程序，还是只是船员们不想把真话说出口时的说话方式。每当一个航次从预报里没有的风暴之间穿过去，就有人耸耸肩，开玩笑说"楼上某人有个好经纪商"，然后整个房间就安静那么一点点。此刻我坐在联盟这条切割船的食堂里，听着它空荡荡的船体在冷却时滴答作响，试图拼凑出一艘生来运送赏金合同的船怎么会装着更像气象账簿而不是任务清单的东西。没人留下过干净的记录；只有半截的笔记、被改道的付款、以及总是对得上同样三四个出发点的迷雾走廊。我唯一确定的是，它始于一座尘球前哨站——那批本该被一周降雨耽搁、结果却没有的货；接着是一个猎人的残骸严重偏航，黑匣子里装着风暴数据；再之后是一座工厂城镇的清单，它的收成死活对不上当地自己的气候报告。
1524	我回到这块岩石上，是因为那噪声不肯闭嘴。你站在山脊上，只听得到风声，可一旦接进本地的中继站，就像在听一个囤积狂的阁楼：删了一半的延时探测、成了孤儿的状况代码、排着队发给死了十年的收件人的消息。联殖撤走勘测无人机时，这地方本该被清扫干净。可它没有。有人跳过了一步，或者假装跳过了，而他当年推进缓冲区的那些东西，就被留在了同样的疏漏里。\n\n我一直在重放一个碎片：一个不属于任何登记飞船的航路标签，以过于规律的间隔脉动着，不像是幽灵数据。那名死去特工潦草写下的坐标、我从一个受惊农民手里买来的那块数据板，甚至那个关于武装护航队在夜间发光田野上空盘旋的故事，全都朝同一个名字弯过去。感觉像人人都看到了一块碎片却耸耸肩，太忙或太怕，没去加起来。如今我正站在他们忽略掉的东西当中，琢磨这信号已经等了多久，才等到有人终于注意到它。
1235	我趁自己还没失去勇气、把那块数据板扔回我发现它的箱子里之前写下这些。在这外面，清单上还是油污和潦草的字迹，可那艘拖船周围的数字却整齐得过分。错的船体 ID、错的航路戳记，还有三个不同的缩写签名在"修正"同一个错误。我问当班的文员是谁改的；她赌咒说自己只是照抄加加林发来的东西。船坞老板说，是因为一名联殖代表为它担保，他才签了字。等我终于通过一条延迟严重的频道联系上那名代表，他坚称请求来自"上面"，然后挂了通讯。没人承认这个决定是自己做的，可他们全都是先从别人那里听来的。\n\n我总想着那艘切割船，想着它的航线就那么断了，被一艘从不出现在任何合法调度单上的幽灵快船取代。起初是一个运货船员的传言，他赌咒说泰坦上一整队船员消失了。然后是纪念墙上一个烧得只剩一半的名字。如今是我自己的笔悬在账簿上方，决定要不要假装没看见一艘船被悄悄推进那条本不该存在的墓地航线。
1120	我上这儿来是为了照看一排半死的传感器、喝点烂咖啡，不是来绊进别人留下的鬼痕里。那座小屋看着像废弃了，除非你知道该往哪儿听；在风声和吱呀作响的桅杆底下，是中继站稳定的滴答声——三个版本之前的软件仍在咀嚼天空和地面，像没人告诉过它战争已经结束。一半的船员轮着来，在维护表上签个字，从不检查系统究竟在标记什么。今天我挖进了那条被忽略的队列——多年来一直把异常自动归成"大气现象"的那条——然后它就在那儿：一条干净的热成像线切开山脊，太直，不像天气；太顺滑，不像野生动物；由一个没人记得谁写的过程记录并盖上了时间戳。我到镇上打听，忽然间每个人的记忆都变得非常方便；治安官记得有场风暴，飞行员记得"仪器噪声"，酒保赌咒说那晚很安静。唯一没对我说谎的，就是这段被遗忘的代码——在信任它的人早已不再留意之后很久，它仍在干着自己的活。
1444	我本不该碰这案子，至少不是正式地碰。我只是他们丢在野外拖车里的副手，负责整理报告、假装边境很平静。可昨天，在清理一桩旧运输队案子时，我调出了联殖为"协调"而与我们共享的原始交通数据突发。有人切我们这份副本切得很马虎。他们数据显示是一次干净交接的地方，却是一片静电；一个时间戳与引擎点火日志对不上；还有一个早该在好几个周期前就退役的中继站 ID。\n\n把它擦干净的人干得很急，笃定没人会看第二眼。他们几乎说对了。我把那个中继站 ID 与更早的事件交叉比对，发现它在三起不同的"导航故障"背后回响，永远是同一座被遗忘、漂在主走廊外不远的监听站。活下来的船长们一直怪星图太便宜或运气不好，而指挥部乐得让他们这么想。我什么都还没上报。我只知道，那股把你正在追的浮标掰弯的干扰，曾经从那只死去的联殖耳朵里弹过一次；而每一次它这么做，就有一支运输队陷入了黑暗。
1698	我在棚屋里录下这段，趁自己还没失去勇气、把整批东西卖给出价最高的人。这里的墙壁渗着冷凝水和偷来的电，一堆锈蚀天线和半烧毁的路由器在再无哪个理智的港务局会检查的频率上嗡鸣。这就是她的通讯会冲到我门口的原因。\n\n它并不是以某种宏大启示的形式到来的。只是频段里的一次双重回响，两支在任何清单上都不存在的、一模一样的运输队，双双消失在一片死寂地带——没人非去不可就不会往那儿飞的地方。我顺着这些鬼穿过好几周的闲聊往回追，穿过深红舰队的死信箱和龙神的旁路频道，直到每条航线都在同一串冰冷的坐标上弹回来。后室里的太空人一直在说"死频道"是个传说、是个英雄、或者是一篇企业抹黑稿，取决于谁欠谁的；可每一次转述都会削掉一点真相。我扒来的原始录音不在乎故事。它们全都指向同一个地方——她链条上的下一座中继站，一座漂在黑暗中、被遗忘的联殖节点，在那里信号归于寂静，谎言不再只是传言。
1334	我在没人能从背后偷看的地方写下这些。在这外面，星星太亮，空气太稀薄，谈不上舒服，但至少只有我这一双耳朵。我从巡逻网格里调出最近三个月的传感器扫描，它们被埋在例行的走私警报和流星警告后面。噪声里有图案：一处微弱的重力干扰涂抹，反复出现在同一条狭窄的轨道带里。它不在任何飞行计划上，却以和那些被指挥部一再改名的"孤立故障"相同的时序脉动着。\n\n我试着在待命室里提起它时，房间以一种谨慎的方式安静下来。没人说我错了，没人要求看数据。他们只是找到了别的方向去看。就是这样我才知道自己离得近了。那特征从这块岩石的背面爬上来，恰好在六年前一座弃用的通讯平台失踪的地方消失。先是那个死缓存，然后是那艘带着跃迁伤痕的货船，现在又是空轨道上的一道重力暗影，全都共享同样的几何。不管她在做什么，她每次都走在同一条看不见的线上。
